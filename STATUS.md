## Структура репозитория

```
index.html                 главная, концепт v6 «Spec» (ч/б, цвет только в картинках проектов), единый self-contained файл
cases/obzhora/index.html   кейс «Обжора» — собранная страница (~5.6 МБ, все картинки в data-URI)
src/
  wrap.py                  оборачивает артефакт-HTML (начинается с <title>) в полный документ: doctype, meta, og, lang=ru
  cases/obzhora/
    obzhora-template.html  исходник кейса с плейсхолдерами {{mock:x}}, {{scr:x}}, {{ic:iNN}}, {{svg:x}}, {{iconrow:n}}
    build.py               подставляет ассеты из out/ в шаблон → obzhora-case.html
    out/                   готовые ассеты: mock/*.webp (экраны в мокапе, _l светлые, _d тёмные), screens/, icons/i00–i74.png, donut.webp, chips.svg, waves.svg
history/                   журнал сессий (см. history/README.md)
STATUS.md                  этот файл
```

Сборка кейса: `python3 src/cases/obzhora/build.py && python3 src/wrap.py` → обновляет `cases/obzhora/index.html` (и `index.html` из артефакта главной, если он есть).
Исходники Figma-экспортов (≈100 МБ PNG) в репозиторий не кладём; они нужны только для регенерации `out/`.

## Принятые дизайн-решения (не ломать без согласования с Андреем)

- Главная: строго ч/б, Unbounded + Golos Text + JetBrains Mono; тёмная/светлая тема, переключатель RU/EN (EN пока не выровнен), кастомный курсор только на устройствах с мышью.
- Кейсы: ультрасовременные, с «парящими» элементами. Параллакс только от скролла (плавный диагональный разъезд + лёгкое покачивание), никакой реакции на движение мыши.
- Кейс Обжора: хиро по фрейму Андрея из Figma (зелёное пятно, наклонённый телефон, 3 пончика на разной глубине), логотип ничем не перекрывается, телефон — его собственный мокап iPhone 11 из Figma (не CSS), тёмная тема по умолчанию с тёмными экранами, в светлой — светлые экраны. Никаких битых PNG-композитов, иконки-«дождь» и сердечки убраны.
- Главная и кейс пока не связаны ссылками (в списке работ Обжора ведёт на Behance) — это запланировано.
- Текст «О себе» надо обновить: сейчас 60–70% задач через ИИ, по факту 90–95%, включая сборку дизайн-систем и прототипов.

## Рабочий процесс

- Андрей даёт ссылки на Figma (или кладёт .fig в рабочие Drafts), Claude тянет экраны/ассеты через Figma MCP, собирает, Андрей проверяет в Chrome на компе и на телефоне.
- Каждую версию кейса фиксируем git-тегом (`case-obzhora-v1…v7`), главную — `v6-spec-bw`, запуск — `site-v1-prelaunch`.
- Деплой: push в `main` → GitHub Pages пересобирает за 1–2 минуты. Для правок с телефона используется сессия Claude Code (вкладка Code) с привязанным репозиторием; GitHub-приложение Claude установлено на репозиторий.
- В конце сессии Claude добавляет файл в `history/` и обновляет этот STATUS.md.
