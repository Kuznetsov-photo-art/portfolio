# История проекта

Здесь хранится журнал работы над сайтом — чтобы в будущем любая модель (или человек) могла восстановить контекст и продолжить правки.

Правило: в конце каждой рабочей сессии Claude добавляет файл `YYYY-MM-DD-<тема>.md`:
сводка решений и изменений + дословный диалог сессии. Файл коммитится вместе с кодом.

Текущее состояние проекта (что сделано, что в планах) — в `../STATUS.md`.
