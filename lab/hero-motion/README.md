# Лаборатория хиро

Ветка `lab/hero-motion`, на сайт не попадает (публикуется только main).

- HERO1 — текущий хиро сайта, метка `HERO1` (main, ba0ce4c).
- HERO2 — черновик моушн-интро, 15 секунд, заканчивается кадром HERO1: `hero2.html`, записи `hero2-v02-desktop.mp4`, `hero2-v02-mobile.mp4` (v01 — в метке hero2-v01).
  Сцены: точка → линия → сетка 12 колонок; слова «Продукты / Дизайн-системы / × AI» со сменой веса и замерами; доска дизайн-системы (курсор, кнопка, тумблер, чипы, шрифт, шкала отступов) со сменой темы кругом из тумблера; доска рассыпается на точки, они собираются в имя; имя проявляется, волна веса; линейки, спецификация, слоган, мета — как в HERO1.
  v02: живой фон HERO1 (тот же шейдер; световое пятно ведёт за действием, после ролика — за курсором), светлая тема и английский — из тех же ключей localStorage, что у сайта ('theme', 'lang'); финальный кадр выверен по замерам HERO1 (1440×860 и 390×844).
  Просмотр: `hero2.html` с сервера сайта; `?clean` — без панели, `?theme=light`, `?lang=en`; `__seek(t)` — кадр для записи.

Новые сохранённые варианты — HERO3, HERO4 и т. д.
