# Лаборатория хиро

Ветка `lab/hero-motion`, на сайт не попадает (публикуется только main).

- HERO1 — текущий хиро сайта, метка `HERO1` (main, ba0ce4c).
- HERO2 — моушн-интро, 15 секунд, заканчивается кадром HERO1. Рабочий файл `hero2.html`.

## Версии HERO2

Каждая версия — метка `hero2-vNN` на GitHub + копия `versions/hero2-vNN.html` + записи `video/hero2-vNN-*.mp4`. Откат — скопировать нужную копию в `hero2.html`.

- v01 — сцены: точка → линия → сетка 12 колонок; слова «Продукты / Дизайн-системы / × AI» со сменой веса и замерами; доска дизайн-системы (курсор, кнопка, тумблер, чипы, шрифт, шкала отступов), смена темы кругом из тумблера; доска рассыпается на точки, они собираются в имя; имя проявляется, волна веса; линейки, спецификация, слоган, мета — как в HERO1. Фон — простое свечение.
- v02 — живой фон HERO1 (тот же шейдер; световое пятно ведёт за действием, после ролика — за курсором); светлая тема и английский из тех же ключей localStorage, что у сайта ('theme', 'lang'); финальный кадр выверен по замерам HERO1 (1440×860 и 390×844).
- v03 — склейка с загрузчиком: первые ~1,6 с только цвет загрузчика и точка (без живого фона), фон проявляется вместе с сеткой; в лаборатории копия загрузчика со шторкой (кнопка «С загрузчиком», по умолчанию при открытии); записи начинаются с загрузчика.

Просмотр: `hero2.html` с сервера сайта; `?clean` — без панели и загрузчика, `?theme=light`, `?lang=en`; `__seek(t)` — кадр для записи (t < 0 — загрузчик, если `__withPre=true`).

Новые сохранённые варианты — HERO3, HERO4 и т. д.
