# Рилс: главная по деталям

Ветка `lab/reels`, на сайт не попадает. Формат Instagram Reels: 1080×1920, 30 к/с, 20 с, H.264 + AAC.

- `capture.py` — снимает главную andrewkuznetsov.com (телефонная вёрстка 390 → 1080 px) отдельными прозрачными слоями, тёмная и светлая тема, + manifest.json с местами слоёв (папка cap/, не в git — пересобирается).
- `beat.py` — оригинальный трек, синтезирован с нуля (без сэмплов и чужого аудио): 124 BPM, фа минор, 20 с → reel1-beat.wav (не в git — пересобирается), превью reel1-beat-preview.m4a.
- `reel1.html` — монтаж на canvas: интро (точка, «Собираю / продукты / по / деталям» в долю), дроп на 3,87 с, сборка страницы сверху вниз по биту (рамка-размер «W × H» на каждой детали), смена темы кругом на 11,6 с, отъезд в колонку, финал с адресом. `__seek(t)` — кадр.
- `record.py <url> <out.mp4>` — запись кадров в headless Chrome + звук.

- `reel2.html` — версия 2 (3D-разборка, DOM + CSS 3D): интро — на каждый удар крупный план одной детали сайта в фокусе, остальные размыты вокруг; с дропа детали по биту падают сверху вниз на наклонную плоскость страницы (ракурс меняется каждый такт, «щелчок» света при приземлении); смена темы кругом на 11,6 с; общий план; финал — хиро анфас. Без добавленных надписей, только содержимое сайта и его шрифты.

Версии: метки `reel1-vNN`, записи в `video/` (v01 — reel1.html, плоская сборка с подписями — Андрею не понравилась; v02 — reel2.html).

## REEL2 — product film (черновик, 13.10.2026)

Своя версия в духе презентаций Apple: `reel3.html?mode=phone|desktop|both`, трек `beat2.py` (120 BPM, ре минор, 22 с, кинематографичный гибрид).
