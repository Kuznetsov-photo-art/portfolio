Privacy

Обновлено 11 октября 2026Updated October 11, 2026

Это личное портфолио. Здесь нет форм, регистрации, аналитики, рекламы и cookie — сайт ничего о вас не собирает

This is a personal portfolio. There are no forms, sign-ups, analytics, ads or cookies — the site collects nothing about you

01

Что хранится в вашем браузере

Только ваши настройки, чтобы сайт их помнил:

  • язык RU или EN и светлая или тёмная тема — в localStorage
  • отметка, что заставка уже показана, и место, где вы остановились на главной, — в sessionStorage, до закрытия вкладки

Эти данные не покидают ваше устройство, их можно удалить в настройках браузера

What is stored in your browser

Only your settings, so the site remembers them:

  • RU or EN language and light or dark theme — in localStorage
  • a flag that the intro has been shown and your scroll position on the home page — in sessionStorage, until you close the tab

This data never leaves your device, and you can clear it in your browser settings

02

Хостинг

Сайт размещён на GitHub Pages. Как любой хостинг, GitHub может записывать технические данные запросов — IP-адрес, время, браузер — для безопасности и работы сервиса. Подробнее — в Заявлении GitHub о конфиденциальности

Шрифты и все файлы загружаются с этого же сайта, запросов к сторонним сервисам нет

Hosting

The site is hosted on GitHub Pages. Like any host, GitHub may log technical request data — IP address, time, browser — for security and to run the service. See the GitHub General Privacy Statement

Fonts and all files are served from this site, with no requests to third-party services
